# «Уроки» — пошаговое обучение (контракт между частями)

Отдельное приложение в папке `learn/` того же репозитория → `https://scvals.github.io/learning-tracker/learn/`.
Тот же стек, что у трекера: HTML/CSS/ES-модули без сборки. Тот же домен → общий `localStorage`,
поэтому уроки используют хранилище трекера (`../js/store.js`) и его синхронизацию (`../js/sync.js`):
выбранное оформление общее, «Готово» в уроке ставит галочку задания в трекере, прогресс уроков синхронизируется.

Повторно используется из трекера (не копировать!): `../css/base.css`, `../css/themes.css`, `../js/ui.js`, `../js/icons.js`,
`../js/themes.js`, `../js/decor.js`, `../js/store.js`, `../js/dates.js`, `../js/sync.js`. Описание классов и API — `../CONTRACT.md`.

Аудитория: один взрослый человек, **полный новичок в вязании**, в английском знает алфавит и простые слова,
пишет левой рукой ради развития мозга (правша). Обращение **на «ты»**, дружески, коротко, без канцелярита,
поддерживающе. Русский язык. Всё должно быть понятнее исходной таблицы плана: маленькие шаги, конкретика (сколько петель, сколько минут).

## Курс навыка (`learn/content/<skill>.js`)

```js
export default {
  skillId: 'knit',               // совпадает с id навыка в трекере: knit | eng | left
  title: 'Вязание',
  intro: 'Абзац: чему научишься за 4 недели и как устроен курс.',
  weeks: [                       // ровно 4, по неделям плана
    { week: 1, title: 'Первые петли', goal: 'К концу недели ты…', tips: ['…'] },
  ],
  lessons: [Lesson, …],          // по одному уроку на каждое задание плана (см. task-id ниже), в порядке выполнения
  sessions: {                    // «Занятие дня» (по желанию): блоки на неделю, из них собирается занятие на 10–40 мин
    1: [{ title: 'Разминка пальцев', minutes: 3, text: '…', lessonId: 'knit-1-2' /* необязательно */ }, …],
    2: […], 3: […], 4: […],
  },
};
```

### Lesson

```js
{
  id: 'knit-1-2',                 // `${skill}-${week}-${n}`
  week: 1,
  taskIds: ['t_knit_1_2'],        // id заданий трекера, которые закрывает урок (см. ниже)
  title: 'Набор петель',
  short: 'Одна строка: что сделаешь.',
  why: 'Что это и зачем — 2–3 предложения.',
  minutes: 20,                    // примерно на одно занятие
  need: ['Спицы 4,5 мм', 'Белая пряжа'],
  steps: [                        // 3–8 шагов; каждый — одно действие
    { title: 'Сделай скользящую петлю', text: 'Подробно, 1–4 предложения.', img: 'knit-slipknot' /* id картинки из *-art.js */, tip: 'Подсказка', timer: 5 /* мин, если шаг на время */ },
  ],
  mistakes: [{ problem: 'Петли слишком тугие', fix: 'Как исправить' }],
  check: ['Получилось, если петли ровные и свободно двигаются по спице'],
  videos: ['набор петель на спицы для начинающих'],   // ПОИСКОВЫЕ ЗАПРОСЫ для YouTube, не ссылки
  quiz: [{ q: 'Вопрос?', options: ['a', 'b', 'c'], answer: 1, explain: 'Почему' }],   // 2–4 вопроса
  terms: ['petlya', 'kromka'],    // id терминов глоссария
}
```

Разметка в любых текстовых полях: `**жирный**`, `[[term-id]]` или `[[term-id|текст]]` — ссылка на термин глоссария,
`{{en:word}}` — английское слово с кнопкой озвучки. Больше ничего (никакого HTML).

### Картинки (`learn/content/<skill>-art.js`)

```js
export default { 'knit-slipknot': '<svg viewBox="0 0 240 160" …>…</svg>', … };
```
Чистые схематичные иллюстрации-схемы: спица, нить, руки контуром, стрелки движения. Цвета только через
`currentColor`, `var(--skill)`, `var(--ink)`, `var(--muted)`, `var(--surface)`, `var(--accent)` (атрибутом `style="stroke:var(--skill)"` или `fill="currentColor"`) — чтобы работало во всех 5 оформлениях и в тёмной теме. Подпись-легенда — в тексте шага, не в SVG (кроме коротких меток). viewBox 240×160 или 240×240.

### Глоссарий (`learn/content/glossary-<skill>.js`)

```js
export default [{ id: 'vto', term: 'ВТО', skillId: 'knit', short: 'Влажно-тепловая обработка: …', more: 'Подробнее…', img: 'knit-…' /* необязательно */ }];
```
id — латиница-транслит в нижнем регистре через дефис, уникальные между файлами (префикс не нужен, но не пересекаться).

## Задания трекера (task-id) — `t_<skill>_<week>_<n>`

- knit 1: 1 Купить пряжу, спицы и мелочи · 2 Набор петель (многократно) · 3 Лицевые петли · 4 Кромка · 5 Закрытие петель · 6 Образец платочной вязки 20×30 рядов
- knit 2: 1 Спущенная петля, распускание, подсчёт · 2 Изнаночная петля · 3 Чулочная гладь · 4 Резинка 1×1 и 2×2 · 5 Образец плотности из белой пряжи, стирка, расчёт · 6 Набрать петли шарфа
- knit 3: 1 Связать примерно половину шарфа · 2 Присоединить новый клубок
- knit 4: 1 Закончить шарф · 2 Закрыть петли · 3 Спрятать концы · 4 ВТО · 5 Образец по простой схеме
- left 1: 1 Постановка листа и хвата · 2 Разминка · 3 Прописи с упором на аккуратность · 4 Контрольный образец №0
- left 2: 1 Соединения букв и слова · 2 Линии, штриховка, круги, спирали · 3 Переписывание наполовину на английском
- left 3: 1 Косая линейка (если критерии выполнены) · 2 Квадрат, треугольник, звезда · 3 Копирование простых рисунков
- left 4: 1 Обычная линейка · 2 Письмо под диктовку · 3 Графические диктанты · 4 Контрольный образец №1
- eng 1: 1 Алфавит и правила чтения · 2 to be · 3 Местоимения · 4 ~100 частых слов · 5 10 мин медленного видео в день
- eng 2: 1 Present Simple · 2 Числа и время · 3 +100 слов · 4 Первые диалоги в чате
- eng 3: 1 there is/are, can, have, вопросительные слова · 2 +100 слов · 3 Голосовые разговоры · 4 Shadowing 5 мин
- eng 4: 1 Past Simple и 20 неправильных глаголов · 2 +100 слов · 3 Рассказ о вчерашнем дне · 4 Первая минутная запись себя

Связь с журналом трекера (показатели недели): вязание — длина шарфа (см), ошибок исправлено самостоятельно;
левая рука — этап (прописи → соединения и слова → косая линейка → обычная линейка → клетка → письмо на скорость),
время на контрольный текст (сек), разборчивость 1–5; английский — слов в Anki всего, % понятого в контрольном видео
(раз в 2 недели), записал минутный рассказ. Уроки должны объяснять, **как** измерить и куда записать эти числа.

## Доп. материалы

- `knit-extra.js`: `export const shopping = { intro, items:[{ name, detail, why, optional? }], yarnExplained:'что такое пряжа (для человека, который не знает)', scarfCalc:{ text, … } }`.
  Шарф: **белый, длина ~160 см**, ширину предложить (≈20 см), рассчитать моток/метраж, спицы, вязку для шарфа новичка.
- `eng-words.js`: `export default [{ week:1, title:'Самые частые слова', groups:[{ title:'Местоимения', words:[{ en:'I', ru:'я', ipa:'aɪ', sound:'ай', ex:'I am here.', exRu:'Я здесь.' }] }] }]` — **по ~100 слов на неделю, 4 недели**, без повторов, от самых частых. `sound` — произношение русскими буквами, `ipa` — транскрипция.
- `eng-dialogs.js`: `export default [{ id, week, title, goal, level, prompt:'Готовый текст запроса для ИИ (Claude/ChatGPT) на русском, который настраивает ИИ быть терпеливым собеседником-учителем на нужную тему недели…', phrases:[{ en, ru }], tips:['…'], voice: bool }]` — 2–3 сценария на неделю; недели 3–4 — голосовые.
- `left-worksheets.js`: `export const sheets = [{ id, title, desc, week, kind }]` и `export function renderSheet(id, opts) → строка SVG страницы A4 (210×297 мм, viewBox '0 0 210 297')` для печати: косая линейка, узкая/обычная линейка, клетка, линии/штриховка, круги/спирали, фигуры для обводки, графический диктант, прописи букв с пунктиром для обводки. Чёрно-серые линии (печать), без CSS-переменных.
  Плюс критерии перехода по этапам (`export const stageCriteria = [{ stage, from, criteria:[…] }]`).

## UI (папка `learn/`)

Маршруты (hash): `#/` дорожка, `#/skill/<skillId>`, `#/lesson/<id>`, `#/session`, `#/words`, `#/dialogs`, `#/sheets`, `#/glossary`, `#/glossary/<id>`, `#/shop`, `#/guide`, `#/guide/<screen>`.
Прогресс: `store.learn('lesson:<id>')`, `store.setLearn('lesson:<id>', { steps, done, quizBest })`, слова: `word:<en>` → `{ known, seen }`.
«Готово» в уроке: `store.patch('tasks', taskId, { done: true })` для всех `taskIds`, которые есть в трекере.
«Занятие дня» в конце предлагает `store.setDay(today, skillId, { done: true, minutes })` (по желанию).
